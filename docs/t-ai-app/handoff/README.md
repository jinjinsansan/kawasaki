# Handoff: T-AI新報 会員版（会員サイト プロトタイプ）

依頼文：`docs/t-ai-app/design-prompt.md`。デザインは販売LP v4（`t-ai/index.html`）と同じ競馬新聞の世界観です。

## ファイル
- `index.html`：動くプロトタイプ。1ファイル、ビルドなし。外部から読み込むのは Google Fonts だけです。`t-ai-app/index.html` としてそのまま置けます。
- `captures/`：390px幅で撮ったキャプチャ。正解の見た目はこれを見てください。

## データと計算（本番で差し替える場所）
- **DATA**：`const DATA = makeSampleData();`。依頼文と同じ形で、`updatedAt / member / races[]`（各レースに `horses[]`：no, gate, name, jockey, weight, last, prob, rank, note, result）を持ちます。足したキーは次の4つです。
  - `week`：今週の開催日の配列
  - `today`：一面に出す日
  - `field`：頭数
  - `notices[]`：お知らせ
- 本番では、`makeSampleData()` を、データベースから同じ形のJSONを読む処理に置き換えるだけで動きます。
- 見本の中身：10/11〜11/22 の14日分、京都・東京 各12R、馬名・騎手・レース名はすべて架空です。
  - 11/21まで：`status:'done'`（着順は確率どおりにランダムで決めています）
  - 11/22：1〜11Rは `ready`、12Rは `waiting`（出馬表待ち）
  - 海外から初出走の馬（`note:'overseas'`）がいるレースだけ、注記を出します。
- **CALC**：計算はこの1か所だけです（Harville法）。
  - `combos(race, kind)`：組み合わせを確率の高い順に返す
  - `one(race, kind, nums)`：1点の確率
  - `hit(race, kind, tickets)`：複数点のうちどれかが当たる確率
  - 単勝・馬連・3連複は1点ずつの確率の合計です。ワイドは当たりが重なるので、3着までの並びを全通り数えて計算しています。
  - kind は `tan / uma / wide / fuku` の4つです。

## 画面（下のタブ：一面／出馬表／買い目／成績／会員）
| 画面 | 内容 |
|---|---|
| ログイン `#/login` | 題字と「会員専用」の判子、メール欄だけ。何を入れても（空でも）進めます。→「ログイン用のリンクを送りました」`#/sent` →（試作）開く |
| 一面 `#/home` | 開催・全レース・計算済み・出馬表待ちの数字、最終更新。本日のメイン（上位4頭の棒と、1番手を赤丸）。「言い切る」＝勝つ確率30%以上の馬の一覧。土曜の答え合わせ |
| 出馬表 `#/races` | 開催日と競馬場を切り替え。1〜12Rの目次。右側は次のどれかを表示：計算済み＝◎の馬と確率／出馬表待ち＝赤い判子／終了＝1着の馬とT-AIの順位 |
| レース詳細 `#/race/ID` | 馬柱（枠の帯・馬番・印・馬名・騎手・斤量・前走・勝つ確率・順位・棒）。馬番順と確率順を切り替えると、行がその場で並び替わります。印◎○▲△は確率の上位4頭に自動で付けます。30%以上は赤字＋赤丸、5%未満は薄く。終了したレースは着順を出し、1着を赤丸。組み合わせ（馬連・ワイド・3連複）は上位20件＋「もっと見る」で、終了したレースは的中に判子 |
| 買い目 `#/build/ID` | レースを選ぶ → 券種（単勝・馬連・ワイド・3連複）→ 買い方（ボックス／軸1頭の流し）→ 馬番をタップ。画面下の札に「この買い目が当たる確率」と点数がその場で出ます。予算を入れると、1点あたりの金額を100円単位で出します。買い目の一覧は開閉。流しは、1回目のタップが軸（赤）、2回目以降が相手（赤枠）です |
| 成績 `#/results` | 月を切り替え。確率帯ごとの頭数・予測の平均・実際の勝率（LPの第3面と同じ形）。T-AIの1番手が勝った数。日ごとの1着の馬（1番手が勝ったときは赤丸）。タップでそのレースへ |
| 会員 `#/my` | 会員証（名前・プラン・利用期限・残り日数・T-AIの角印）。お知らせ、公式LINE、ログアウト |

## 動き
- 画面の切り替え：0.24秒、6px下から現れます。
- レース詳細を**初めて**開いたとき：上の黒い帯に「計算中…」と出て、輪転機の目盛りが1.25秒で伸びます。確率の数字は活字が組まれるように次々変わってから止まり、棒が1秒で伸び、最後に赤丸を描きます。2回目からはすぐに表示します（開いたレースは localStorage `taiapp:seen` に記録）。
- 並び替え：0.45秒で行が動きます。
- 赤ペン：SVG の stroke-dashoffset で、0.8秒で描きます。
- 買い目：タップした瞬間にボタンの色が変わり、確率の数字が0.35秒で数え上がります。対応する端末では 6ms 振動します。
- 長押しで文字が選ばれないようにしています（`user-select:none`・`-webkit-touch-callout:none`）。入力欄は除きます。
- 動きを減らす設定の端末では、演出なしで表示します。
- 360px幅でも横にはみ出しません。タップできる場所は44px以上です。

## 本番で決めること
- 「リンクの有効期限30分」は仮の値です。実際の値に合わせてください。
- 確率帯の区切り（5／10／20／30%）と、「言い切る」の基準（30%）。
