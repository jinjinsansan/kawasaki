# 挿絵の計画（案）

縦スワイプ（A案）の画面に、1画面まるごと絵の画面を差し込む。「絵 → 文章 → 絵 → 文章」のリズムにする。
絵は Codex（ChatGPT ログイン・組み込みの画像生成）で描く。手順は anger プロジェクトの `anime/TASK_PC.md` と同じ。

- キャラクター：川崎さんのアニメ版（`ref/` の公式画像）。`CHARS.txt`
- 絵柄：`STYLE_INK.txt`（墨線＋金）か `STYLE_COLOR.txt`（落ち着いたカラーアニメ）。試し描き `test/` を見て決める
- 絵の中に文字・ロゴ・吹き出しは入れない（原稿は一字一句そのまま本文で読ませるため）
- 実在の人物（騎手・予想家など）に似せない
