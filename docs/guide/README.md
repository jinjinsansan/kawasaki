# T-AI 使い方マニュアルサイト デザイン依頼書（2026年11月23日）

T-AI会員サイトの使い方を、使い方ごとに分けて見せるマニュアルサイトを、別のサブドメインで作ります。会員向けのマニュアルであり、未購入の方に「こんなことができる」と見せる役目も兼ねますが、募集・申し込みの案内は載せません。デザインは派手め（ギラギラ）でお願いします。

## 1. 目的と読み手

1つのサイトで、2種類の読み手に向けて作ります。

| 読み手 | 知りたいこと | このサイトで見せること |
| --- | --- | --- |
| 会員さま | どの画面で何ができ、どう使えば迷わないか | 使い方ごとの手順。短く、画面の写真つき |
| 未購入の方 | 買うと何ができるのか | 同じ使い方を「こんな使い方ができる」として見せる。募集・申し込みの案内は載せない（ガイドページのため） |

使い方の説明は、簡単で分かりやすく。1つの使い方を、写真1〜2枚と3〜4行の手順で読めるのが目安です（川崎さんの希望）。

## 2. サイトの基本

- 場所：guide.clubkawasaki.net（決定）
- 見る端末：ほぼスマホ。幅320〜430pxで崩れないことが最優先。パソコンでも読める程度に
- 関係するサイト：会員サイト https://t-ai-app.clubkawasaki.net （ログインが必要。マニュアルの各使い方から「この画面を開く」で飛ぶ）
- 作り：1枚の縦長ページ＋使い方ごとの見出しへ飛べる目次。ログインは不要（誰でも読める）
- 公開の仕組み：組み込み・公開はこちら（開発側）で行います。デザイナーさんはデザインの形で納品してください（7章）

## 3. デザインの方向

川崎さんの希望は「ギラギラ」。派手で勢いのある見た目にしつつ、使い方の手順はすぐ読めることを両立させてください。

- 派手にしてよいところ：一番上（ヒーロー）、使い方の見出しと番号、v2エンジンの見せ場
- 落ち着かせるところ：各使い方の手順の文と、画面の写真のまわり（読む場所なので、背景と文字の差をはっきり）
- 今あるものとのつながり：申込LPは「T-AI新報」という新聞の紙面のデザイン（生成りの紙・黒・赤 #c1121f）。会員サイトも同じ色づかいです。マニュアルは別の派手な見た目で構いませんが、T-AIのロゴの書き方と赤は合わせてもらえると、同じ商品だと分かります
- 避けたいこと：小さすぎる文字（本文は16px以上）、写真の上に文字を重ねて読めなくなること、横スクロール

## 4. ページ構成

上から順に並べます。

1. ヒーロー：「T-AI 使い方マニュアル」のような大きな見出し（使い方の数は後で増えるので、見出しに数を入れない）。会員サイトの画面の写真を派手に配置
2. 3つの基本操作：ログイン（6桁のコード）→ 今日のレースを選ぶ → 出馬表を見る。各写真1枚＋1行
3. 使い方の目次：使い方ごとのアイコン付きのタイル（今回8個、後で足せる形に）。押すとその使い方へ飛ぶ
4. 使い方（5章）：各々「こんな人に」→ 手順（3〜4行）→ 画面の写真 →「この画面を開く」ボタン
5. よくある質問：ログインのコードが届かない、ホーム画面への追加、通知の設定など（文はこちらで用意）
6. 注意書き：小さく、ただし読める大きさで（6章）

## 6. 表現の決まりごと

派手なデザインでも、文言は次を守ってください。文の最終版はこちらで確認します。

- 利益の約束をしない：「何もしなくてもプラス」「必ず勝てる」は使わない。使い方10（v2）は「v2の買い目をコピーして、そのまま買える」と書きます
- 数字は申込LPと同じものだけ：v2の検証実績（回収率111.2%・108.4%など）を載せる場合は、LPの第7面と同じ数字・同じ注記で
- まだない機能をあるように見せない
- 入れる注意書き：「過去の検証結果で、将来の払い戻しや利益を約束するものではありません」「馬券は会員さまご自身で、JRAの即PATから購入します」
- 会員さまの個人情報を写さない：画面の写真にメールアドレスや自分の収支が写らないよう、写真はこちらで用意します
