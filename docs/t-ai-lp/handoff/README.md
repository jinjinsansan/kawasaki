## 考え方
「AIの操作画面」をやめ、ターゲットが毎週見慣れている**競馬新聞**の紙面にしました。地は新聞紙の色、文字は墨、強調は赤（赤ペン・判子・見出し）。黒は見出しの帯と表の頭だけに使います。

- 主ボタン：赤地・白文字・墨の2px枠＋4pxの墨の影（押すと沈む）。副ボタンは紙地。

## 紙面の構成
- **題字**：「T-AI新報」＋二重罫＋赤い「号外」の判子
- **一面**：「競馬は、予想じゃない。」を縦書きの大見出し（2行目は赤）。23.4%の小さな表を赤ペンで丸囲み。黒い帯に「当てるな。選ぶのもやめろ。」
- **序章**：印◎○▲△つきの「根拠」の表を赤ペンで消し、手書きで「根拠なし」。言い切りは大きな見出し。「何もしないで勝つ。」は黒地で赤丸囲み
- **第1面 独占手記**：川崎さんの写真（白黒）と署名欄。決め台詞は囲み記事、区切りの文は白抜きの中見出し、大事な言葉は赤い下線
- **第2面 解剖**：8頭立ての「予測勝率表」（イメージ。合計100%）。23.4%を赤丸、棒が伸びる
- **第3面 成績**：検証成績の表（数字は数え上げ、「1ポイント以内」は赤丸）。10頭・20頭は馬番のマスで勝つ番号を黒く塗って赤丸
- **第4面 券種**：券種の表に赤ペンのチェック。16,887は赤い大きな数字
- **第5面 論説**：検証方法は「一・二・三」。壊す側（黒）／壊される側（紙・赤）の対比表。体験デモはキリトリ線の枠
- **全面広告（料金）**：二重線の広告枠。2027年末プランは赤い太枠＋赤い影＋「推奨」の判子。保証書は白い紙に「川崎タカシ」の角印。条件の詳細は開閉
- **最終面 主筆より**／**Q&A 読者の疑問**（タップで答えが開く）／最後の申込

## 動き（軽め）
- 赤ペン：見えたら線・丸・チェックが0.9秒で描かれる（SVG stroke-dashoffset、`[data-pen]` に `.drawn`）

- 数字：見えたら1.4秒で数え上げ（`[data-to]`）／段落：0.8秒で浮かぶ（`[data-rv]`）

- 動きを減らす設定では、描き終わった状態で表示

## v3 の考え方
ページ全体を1つの見せ方で通さず、章ごとに地の色と動きを変えています。流れは「静かな話 → 証拠 → 決断」です。

| 章 | 地の色 | 見せ方 | 動き |
|---|---|---|---|
| 表紙 | 黒 | 点の格子＋23.4%の弧 | 光の帯が走る |
| 序章 | 黒 | 1画面に一言ずつ／根拠チェックのカード | 浮かぶ／赤い取り消し線 |
| 01 手記 | 焦げ茶 #1d140e〜#1f1610 | 手紙。17px、行間2.25。引用は大きな“ ”付き。最後に署名 | ぼかしから浮かぶ（1.4秒） |
| 　（暗転） | ほぼ黒 #050403 | 「去年、私は大きな病気をしました。」だけを1画面に | — |
| 02 確率エンジン | 方眼の黒＋赤い光 | 計器を画面いっぱいに固定（sticky、420svh）。字幕5枚 | スクロールでリングと数字が0→23.4%、字幕が切り替わる |
| 03 検証 | 黒 | 数字5つを1つずつ全面に（sticky、520svh）→ 10頭・20頭のマス | スクロールで切り替え、数え上げ／マスが順に点く |
| 04 全券種・05 検証方法 | 黒〜深い茶 | 横にめくるカード（scroll-snap） | 指で横にスワイプ、ドットで位置を表示 |
| 壊す側／壊される側 | 上：金／下：赤 | 画面を上下に分割（sticky、260svh） | スクロールで赤が金を押し上げる（境界 62% → 32%） |
| 06 料金 | 金茶 #2a1c0e〜#33230f＋金の光 | ページでいちばん明るい場面。保証書は**紙**（#efe6d2、墨文字、朱の印） | 浮かぶ |
| 07 最後に | ワインレッド #24090c〜#2a0b0e | 吹き出しは**ここだけ** | 吹き出しが順に現れる |
| 08 Q&A | 黒 | 質問＝読者の吹き出し、タップで答えが開く | 開閉 |

- スクロールで動く場面（02・03・分割）は、`[data-scrolly]` の要素のスクロール量（0〜1）で描いています。動きを減らす設定の端末でも、スクロール量に応じた表示は残します（切り替えのアニメーションだけを止めます）。
- 横スワイプはページの中の部品なので、ページ全体の横スクロールは出ません（`body { overflow-x: clip }`。sticky を壊さないよう hidden ではなく clip を使っています）。
- 追加した文言：SIDE A ／ SIDE B、SWIPE →、DEVELOPMENT、署名「川崎タカシ」、カード番号 01〜05、VERIFIED

## 章ごとの仕様
1. **表紙**：画面いっぱいの高さ。背景はCanvasで、22px間隔の点の格子に、金の光の帯がゆっくり上から下へ走ります。右上の大きな円に、23.4%ぶんの金の弧を描いています。
2. **言い切り**（当てるな／人間の脳は〜／何もしないで勝つ）：それぞれ画面の88%の高さを使い、余白で読ませます。
3. **予想の否定**：4つの言葉が画面に入ってから0.7秒後、0.35秒ずつずれて赤い取り消し線が引かれ、文字が薄くなります。
4. **手記（CHAPTER 01）**：背景を少し温かい焦げ茶に変え、文字を大きくしています。強い一文は上下の罫線で挟んだ引用として見せます。最後に署名「KAWASAKI TAKASHI」を置いています。
5. **確率エンジン**：コンソール型のパネルです。リング（目盛り＋金の弧23.4%、2.4秒）と数字のカウントアップで見せます。
6. **検証**：
   - 数字5つを罫線で区切った表にしています。数字は1.8秒で数え上がります。
   - 「10頭中3頭」「20頭中1頭」は、馬番のマスで図にしています。勝つマスが0.6秒後に金に点きます。勝つ番号は見た目の配置だけで、データではありません。
7. **全券種**：英字ラベル、券種、マスの組み合わせ図（ワイドは点線）を1行ずつ並べています。16,887は大きく見せます。
8. **検証の方法**：01〜03の番号付きリストです。「壊す側（金）／壊される側（赤）」は、ほぼ1画面を使って金から赤へのグラデーションの縦線でつないでいます。
9. **体験デモへの導線**（原稿外）：デモと同じパネルの形で、ボタンを押すと tai.clubkawasaki.net を別タブで開きます。
