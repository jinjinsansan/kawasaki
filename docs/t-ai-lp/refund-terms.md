# T-AI 返金保証の条件（案）

2026-11-19 作成。**川崎さんの確認待ち**。原稿の「2大返金保証」の約束はそのままに、「何を・いつ・どう測るか」を、会員が自分で確かめられる形に決めたもの。決まったら、LP の返金保証の欄と `tokushoho`（特定商取引法に基づく表記）の「返品・返金について」に同じ文を載せる。

## 返金保証の条件

### 対象
- **半年プラン（98,000円・税抜）** と **2027年末までのプラン（149,800円・税抜）**
- 対象外：4ヶ月プラン（79,800円）、現会員様の特別アップグレード枠（29,800円）

### 何を測るか
- T-AI が JRA の全レースについて、**発走前に会員ページで公開した各馬の予測勝率（単勝）**
- 公開した時点の数字を記録として残し、あとから書き換えない（原稿の「結果が出る前に予測を凍結」と同じ）
- 取消・除外になった馬は数えない

### どう測るか
1. ご利用期間中に公開した全ての予測勝率を、**5%刻みの確率帯**に分ける（0〜5%未満、5〜10%未満、……、40〜45%未満の9つ）
2. 確率帯ごとに、**予測勝率の平均**と、**実際に1着になった割合**を出す
3. その差が **2.5ポイント以上** になった確率帯が1つでもあれば、返金の対象とする
   - 例：30〜35%の帯で、予測勝率の平均が32.1%、実際の勝率が29.4%なら、差は2.7ポイントなので返金の対象
- **予測勝率45%以上の馬は除く**（原稿どおり。頭数が少なく、数字がぶれやすいため）
- 頭数が少ない確率帯も、たまたまの偏りが大きくなるため、**期間中にその帯に入った馬が200頭未満の帯は判定に使わない**

### 判定の時期
- ご利用期間が終わった時点で、期間全体の数字で判定する
- 半年プラン：利用開始から6ヶ月。2027年末までのプラン：2027年12月末まで

### 会員が確かめられるようにすること
- 確率帯ごとの「予測勝率の平均」「実際の勝率」「頭数」を、毎月、会員ページで公開する
- 期間終了後に、判定結果を全会員に公開する

### 申し出と返金
- 申し出：期間終了の翌月末までに、公式LINEから
- 返金：申し出の確認から30日以内に、参加費用の全額（消費税を含む）を銀行振込で。振込手数料は当方が負担する

### 2027年末までのプランの特約
- 上の条件で返金の対象になった場合は、全額を返金したうえで、**2028年12月末まで無償で利用期間を延長**する

## 決めた理由（川崎さんへの説明用）

- **「2.5%」を「2.5ポイント」と書いた**：「30%の帯で実際が27.5%」のような、差の大きさの意味にするため。「%」のままだと「30%の2.5%＝0.75%」とも読めてしまう
- **確率帯ごとに測る**：原稿の検証結果が「全ての確率帯で1ポイント以内」なので、同じ物差しで約束するのが筋。全体の平均だと、帯ごとのずれが打ち消し合って小さく見え、保証が形だけに見える
- **200頭の下限**：半年でJRAは約1,700レース・約24,000頭。高い確率帯は頭数が少なく、数十頭では偶然で数ポイントずれる。下限がないと、システムが正しくても返金になりうる
- **数字を毎月公開する**：会員が自分で確かめられないと、保証が信用されない。原稿の「嘘のない数字」の主張とも合う
- **申し出の期限と方法**：特商法の表記には、返金の条件と方法を具体的に書く必要がある

## 川崎さんに確認したいこと

1. 5%刻みの確率帯、200頭の下限、期間終了時に判定、でよいか
2. 確率帯の数字を毎月、会員ページで公開できるか（公開の仕組みがなければ、期間終了時の一括公開だけでもよい）
3. 申し出の窓口は公式LINEでよいか
4. 返金は「参加費用の全額」＝税込の支払額でよいか
