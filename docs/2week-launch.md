## 仕組み

### 本LP（`lp2/index.html`）
- 横スワイプ型、全26ページ。どのページも縦スクロールなしで1画面に収まる（390×844／375×667／360×640／430×932 で確認）。
- 構成：ヒーロー → あいさつ2 → 的中実績8（無料5・有料2・皐月賞）→ お客様の声4 → 商品内容 → 申込の流れ → 申込カード → あとがき8。
- 申込URL：`lp2/main.js` の `CTA_URL`（https://takashiskeiba.com/fm/32650/KVgXxhEc）。
- 問い合わせLINE：https://lin.ee/uDgbNni （申込の流れ・特商法・プライバシーポリシー）。
- 参加費：19,800円（税抜）／21,780円（税込）。`lp2/index.html`（2か所）と `lp2/tokushoho.html`。
- 締切：`lp2/main.js` の既定値 2026/10/23 00:00 JST（＝10/22 24:00）。

### 予告ページ（`lp2/teaser.html` ＋ `lp2/teaser.css`）
- 全6ページ：カウントダウン → 無料配信の的中一覧 → 有料配信の的中一覧 → 皐月賞 → 中身を伏せた予告カード → 「今夜20時を、待て。」（LINE通知・Google／iPhoneカレンダー登録）。
- 的中一覧の各行はタップでXの投稿を開く。
- カウントダウンの目標時刻は `<html data-deadline="2026-10-22T20:00:00+09:00">` で指定（`main.js` を本LPと共用）。
- iPhoneカレンダー用：`lp2/takashi-2week.ics`（20:00開始、10分前に通知）。

### 20時の切り替え
- `lp2/middleware.js`（Vercel Routing Middleware）が `/` へのアクセスごとにサーバー時刻を見て、20:00 前は `/teaser` の中身を返し、20:00 以降は本LP（`index.html`）をそのまま返す。URLは変わらない。
- 予告ページを開いたまま 20:00 を迎えた人は、カウントダウン終了の3秒後に `/` を読み込み直して本LPへ。
- 20:00 以降に `/teaser` を直接開いた人は `/` へ移動。

### 確認用パラメータ
| URL | 表示 |
|---|---|
| `/?preview=teaser` | 予告ページ（時刻に関係なく） |
| `/?preview=main` | 本LP（時刻に関係なく） |
| `/teaser?state=closed` | 予告ページの20時以降の表示 |
| `/?state=closed` ＋ `preview=main` | 本LPの締切後の表示 |
| `?now=2026-10-22T19:59:00+09:00` | 任意の時刻を再現 |

## 公開後にやること・注意
- 20:00 に、問い合わせLINE（予告ページの通知ボタンの先）から「公開しました」と一斉送信する。
- 共有用の画像はLINE・Xが保存して使い回すため、反映が遅れることがある（XのCard Validator、LINEのPagePokerで再取得できる）。
- 320×568（初代iPhone SE相当）は対象外。ヒーロー・あとがきなどで縦にはみ出す。
- 予告ページを外す・切り替え時刻を変える場合は `lp2/middleware.js` の `LAUNCH` と `lp2/teaser.html` の `data-deadline` を両方変える。

## 切り戻し（問題が起きたとき）
- 予告をやめて本LPだけ出す：`lp2/middleware.js` を削除してプッシュ（本LPがそのまま `/` に出る）。
- Vercelのダッシュボードの Deployments から、直前のデプロイを「Promote to Production」でも戻せる。
