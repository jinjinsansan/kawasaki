## スワイプの仕様
- 1画面＝ページの高さ（100dvh）。画面の中ではスクロールしません。
- 入りきらない画面は、中身全体を縦横同じ比率で縮めて収めます（`.fit` の `scale`）。余ったときは上下の真ん中に置きます。
  - 測ったときの縮み方：390×844 では28画面すべて縮めずに収まりました。375×667 では、表紙0.82、②0.92、④0.92、料金0.96 で、ほかは縮みません。
  - 書体の読み込みが終わったときと、画面の大きさが変わったときに、測り直します。
- めくり方：画面のどこを触ってもめくれます。
  - 指に画面がついてきて、離したときに画面の高さの16%以上動いていれば次へ進みます。速く払ったとき（0.45px/ms以上）も進みます。
  - 最初と最後の画面では、引っぱると0.28倍だけ動いて戻ります。
  - 移る動きは0.52秒です。
  - 8px動くまではタップとして扱うので、ボタンやリンクはそのまま押せます。めくった直後のクリックは無視します。
- パソコン：マウスのホイール（0.75秒に1回）、↑↓・PageUp/Down・スペース（Shiftで戻る）・Home/End でめくれます。
- 進み具合のバー：上に28本並んでいます。今の画面は光り、見終えた画面は金色になります。タップでその画面へ飛べます。
- 「上へスワイプ」：表紙だけに出して、一度めくったら消します。
- 下の固定の申込ボタン：表紙と最後の申込画面以外では、いつも出ます。中身はボタンの高さ＋14pxを避けて置いているので、ボタンの下に隠れません。余白はCSSのpaddingではなく、測った位置で取っています。
- 動き：数え上げ・棒・ランプ・「簡単すぎて、」は、その画面に初めて入ったときに始まります。段落は0.09秒ずつずらして出ます。放射光・紙吹雪・流れる帯は、表紙にいる間だけ動きます。
- URL：`#5` のように、画面の番号が付きます。その番号で開くと、その画面から始まります。
- 動きを減らす設定の端末では、めくる動きもなくして、すぐに切り替えます。最初から最後の状態を表示します。
