# Handoff: 『2026年 クライマックスプラン』販売LP（climax/）

依頼書：`docs/climax-lp/design-prompt.md`。

## ファイル
- `climax/index.html`：LPの本体。1ファイル、ビルドなしで、そのまま本番に置けます。外部から読み込むのは Google Fonts だけです。`noindex` が入っているので、公開の合図で外してください。
- `climax/ogp.html`：共有用画像の元（1200×630）
- `climax/ogp-v2.jpg`：書き出した共有用画像（受け取った ogp.png 約0.9MB を、組み込み時に JPEG 約0.15MB へ軽量化）。`index.html` では `https://climax.clubkawasaki.net/ogp-v2.jpg` として読み込んでいます。
- `captures/climax-390-full.png`：幅390pxで上から下まで撮った画面

## 差し替える場所
- **申込先**：`index.html` の下のほうの `const APPLY_URL = '#';` の1か所だけです。
  - 申込ボタン4つ（表紙・料金・最後・下の固定）に、まとめて入ります。
  - `https://` で始まるURLにすると、別のタブで開きます。
- 特商法・プライバシーへのリンク：今は `tokushoho.html`・`privacy.html`（同じフォルダ）です。置く場所に合わせて変えてください。
- OGP の URL（`og:url`・`og:image`）：公開するドメインに合わせて変えてください。

## 構成
1. 表紙：赤の放射光（回転）、紙吹雪（canvas）、黒い帯の見出し、金箔の『2026年 クライマックスプラン』、星形の「登場！」、15,000円、申込ボタン。表紙の下に、斜めに流れる帯があります。
2. ごあいさつ：会員さんの声2つを、白い吹き出しで見せます。
3. 1章：
   - 9月・10月・11月のカードと、回収率の棒（棒の高さは、回収率から100%を引いた値に合わせています）
   - 合計（＋10,350円・回収率114.9%は数え上がります）
   - 1点100円／1,000円／5,000円の横棒（長さは金額の比 2%・20%・100%）と、元の注記
   - 「5か月連続プラス」の5つのランプ。7月・8月は「プラス」とだけ表示し、数字は出しません。
4. 2章（赤地）：4枚のカード。
   - ②：G1のレース名を並べた札
   - ③：金の枠、「最大の目玉」の札、光が流れます
   - ④：「note 1記事 2,500円 ▶ 期間中 追加料金なし」の対比
5. 料金：金枠の中に大きい15,000円。2,500円の札6枚＝15,000円の図と、申込ボタン。
6. 3章（赤地）：「簡単すぎて、」を3回、大きくなりながら飛び込ませ、「一体どうやって外します？」を黒い札で見せます。「3連単なら10点以内、馬単なら3点」の大きな枠、札束と金の帯の図。
7. 4章：受付打ち切りの文を、黄黒の斜線と赤枠の囲みで見せます。※の注記は、本文の中で少し小さくしています。
8. 最後：「▼『2026年 クライマックスプラン』ご参加・詳細はこちら」と、大きな赤のボタン。フッター。
- 下の固定ボタン：表紙と最後のボタンが見えている間は隠れます。

## 動き
- 段落・カード：画面に入ると、22px下から0.6秒で出ます。
- 棒：1.1〜1.2秒で伸びます。数字：1.4秒で数え上がります。ランプ：0.22秒おきに点きます。
- 放射光・紙吹雪・帯：表紙が見えている間だけ動きます。`backdrop-filter` や大きなぼかしは使っていません。
- ボタン：3.4秒ごとに光が走ります。押すと沈みます。
- 動きを減らす設定の端末では、すべて止めて、最初から最後の状態を表示します。
- ▶ ▼ は、iPhoneで絵文字にならないよう、文字として表示する指定（U+FE0E）を付けています。

## 原稿について
- 文言は変えていません。変えたのは改行・見出しの置き方・強調だけです。
- 【】は記号を外し、強調（赤の下線マーカー、赤地では黄色の札）に置き換えました。
- 会員さんの声の「・」は、吹き出しにしたので外しています。
- 図の中の数字は、原稿にある数字だけです。
