## 3. 画面の流れ（6画面）

1. **レース**：架空のレース3つから選ぶ（京都11R デモ記念＝買い／東京11R サンプルステークス＝買い／中山10R テスト特別＝見送り）
2. **解析**：約7秒。6種類のデータ（「過去10年の結果」「不利・バイアス」「調教タイム」「馬場・展開」「予測投票数モデル」「直前の投票推移」）から中央の INDEX ENGINE へ光が流れ、各馬の指数が出る。早送りボタンあり
3. **指数**：指数・予測勝率・予測オッズ・期待値の表。並べ替えあり。行をタップすると内訳が出る
4. **判定**：メーターと「買い／見送り」。ベットコントロール（予算1万／3万／5万円の配分）。「投票が10%増えたら？」のスイッチ
5. **資金**：複利シミュレーター（軍資金・期間を動かす）
6. **締め**：「本物の指数と投票システムは、公式LINEからのみ限定公開します。」

## 4. 決めごと・守ること

- **資金シミュレーターの計算式は変えない**：1か月で資金が1.36倍（＝1 + 投票額は軍資金の3倍 × 月8開催 × 回収率の上乗せ1.5%）。記事の表と1円まで一致する（3万円 → 1か月後 40,800円／半年後 189,826円／1年後 1,201,125円。5万円 → 68,000円／316,376円／2,001,875円）。記事の「2年後」の数字は記事の条件では再現できないので、期間は1年までにしている
- **「デモ用のサンプル」の注記は消さない**：本物の予想や実績だと誤解させないため（景品表示法の面での川崎さん側のリスクを避ける）。実在のレース名・馬名・騎手名は使わない
- 画面に出る「実績」の数字は川崎さんの記事にあるものだけ。こちらで作らない
