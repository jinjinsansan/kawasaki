# Handoff: 独自指数＆投票システム 体験デモ v4（AIコンソール）

依頼文：`docs/demo/design-prompt.md` ／ 記事：note「近代競馬に革命を起こす『完璧なAIシステム』がついに完成しました」（2026/11/18）

## Overview
ステップメールの「触ってみる」から開く、スマホ縦向けの体験デモ（6画面）です。v4 では「AIシステムを操作している」感じを強めました。
- 書体をゴシックと等幅に変えました。
- 操作できるボタンを増やしました。
- 文言を記事の内容に合わせました。

## About the Files
`demo/index.html` は**そのまま本番に置けるコード**です（1ファイル、ビルドなし）。外部から読み込むのは Google Fonts だけで、画像は使っていません。`demo/assets/takashi-face.webp` は使っていないので、削除してかまいません。

## Fidelity
High-fidelity です。正解の見た目は `captures/`（390px幅）を見てください。

## v4 の変更
### 雰囲気
- **書体**：明朝体をやめ、**IBM Plex Sans JP**（本文・見出し）と **IBM Plex Mono**（数字・ログ・ラベル）にしました。
- **パネル**：各機能を「パネル」として表示します。上の帯に `MODULE 02 · INDEX ENGINE` などのモジュール名を、右に `RUNNING／READY／DECIDED` の状態を出します。
- **ヘッダー**：顔の代わりに、小さく回る点の球（指数エンジンの印）を置きました。表記は「独自指数＆投票システム ／ POWERED BY T-AI」です。
- **配色**：カワサキクラブ本LP・lp2 と同じです（黒 #0c0a09／ワインレッドの光／ゴールド #e2b857・#f5dc92／赤 #ff4d57／罫線 #3a2a16・#4a3519）。

### 操作できるところ（ボタンを増やした）
| 画面 | 操作 |
|---|---|
| 1 レース | レース3つ（RUN ▸） |
| 2 解析 | 「解析を早送りする」（すぐに完了の状態へ） |
| 3 指数 | 並べ替え（指数順／期待値順／馬番順）。**行をタップすると内訳シートを表示**：6種類のデータごとのスコア、指数・予測勝率・予測オッズ、期待値の計算式（例：37.5% × 3.3 = 1.24） |
| 4 判定 | 予算の切り替え（1万／3万／5万円 → 配分の金額が変わる）。**「投票が10%増えたら？」のスイッチ**（オッズ÷1.1で期待値を計算し直し、メーターと判定がその場で変わる）。「指数表に戻る」「別のレースで試す」 |
| 5 資金 | 軍資金（3万／5万／10万円＋スライダー）、期間（1か月／3か月／半年／1年＋スライダー） |
| 6 締め | 「別のレースで試す」「資金シミュレーターをもう一度」 |

### 記事に合わせて直した点
- **締めの文言**：「一般には公開していません」から、「本物の指数と投票システムは、**公式LINEからのみ限定公開**します。」に変えました。
- **T-AI の位置づけ**：記事では T-AI は「従来のAI」で、今回の商品は「独自指数＆投票システム」です。そのため、主役は「独自指数＆投票システム」にし、T-AI は「POWERED BY T-AI」と小さく添えるだけにしました。中心の表示は `INDEX ENGINE` です。
- **6種類のデータ**：過去10年の結果／**不利・バイアス**／調教タイム／馬場・展開／予測投票数モデル／**直前の投票推移**（記事の「道中の不利や馬場バイアス、直前の不自然な投票推移」に合わせました）。
- **「投票+10%」**：解析のログに `[test] 全体の投票 +10% で期待値を再検証` を入れました。判定の確認項目にも「投票+10%で再検証」を足し、さらにスイッチで実際に試せるようにしました（記事の「仮に全体の投票が10%増えても」に対応）。
- **資金の計算**：式は変えていません（1か月で1.36倍）。3万円・5万円で始めた場合の、1か月後・半年後・1年後の金額は、記事の数字と1円まで一致することを確認済みです。

## デザイントークン（`:root`）
- 地：`--bg #0c0a09`。上に `rgba(122,12,20,.78)` の光、左下に赤のにじみ、115°の金の細い斜線を重ねています。
- パネル：`#1c1411 → #120d0b`、枠 `#4a3519`、角丸10px、赤い外光（`rgba(193,18,31,.28)`）。
- 文字：`--pt #f4ede4` ／ `--pt-2 #d8cdc0` ／ `--pt-3 #b9aea2`。
- 金：`--gold #e2b857` ／ `--gold-hi #f5dc92` ／ `--gold-lo #c9973a`。赤：`--red-hi #ff4d57`（見送り、ストレステスト中）。
- データ6系統：`--d1〜--d6`（彩度を落とした青・茶・緑・黄土・赤茶・藤）。
- 主ボタン：lp2 と同じ金のグラデーションで、ピル型（高さ52px）。副ボタンは金茶の線だけです。
- 区切りボタン：黒い溝の中で、選んだものが金茶に浮きます。
- スイッチ：ONで金になります。

## 動き
- 画面の表示：0.7秒で、8px下から現れます。
- 解析：7.2秒かけて次のように動きます。
  - 中央のコア：回転する点の球、目盛り60本、進み具合を表す円弧
  - 左：6系統から光の粒が流れ込む
  - 右：各馬の手前に6マスの「分析セル」が順に点き、全部点いた馬から指数が出る
- 指数表：上の行から順に光り（走査）、1秒で並べ替わります。並べ替えボタンを押すと、同じ動きで行が入れ替わります。
- 判定：次の順で確定します。
  1. コマンドを打ち込む
  2. 確認項目4つが STANDBY → RUNNING → 結果、と順に変わる
  3. 結果パネルが出る
  4. メーターの針が2秒で最大の期待値の位置に止まる
  5. 判定の文字が、ぼかしと広い字間から定位置に止まる
- 動きを減らす設定の端末では、すべて最終の状態で表示します。
